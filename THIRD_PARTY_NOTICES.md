# Third-Party Notices

Xtractor Community uses the following separately installed dependencies.
Their upstream licenses apply to those components.

- [pypdfium2 and PDFium](https://github.com/pypdfium2-team/pypdfium2)
  provide PDF rendering and text extraction. See the licenses and component
  notices included with the pypdfium2 package.
- [PySide6 and Qt](https://doc.qt.io/qt-6/licensing.html) provide the desktop
  interface. See Qt's licensing documentation and the notices shipped with Qt.
- [openpyxl](https://openpyxl.readthedocs.io/) reads and writes Excel workbooks.
- [Pillow](https://pillow.readthedocs.io/) handles images.
- [Tesseract](https://github.com/tesseract-ocr/tesseract) and the English
  language model are installed separately for optional OCR.

This source checkout contains no dependency wheels, OCR models, or
redistributed application executable.
