Third-Party Notices

Xtractor Community uses the following separately installed dependencies. Their upstream licenses apply to those components.

  • pypdfium2 and PDFium provide PDF rendering and text extraction. See the licenses and component notices included with the pypdfium2 package.
  • PySide6 and Qt provide the desktop interface. See Qt's licensing documentation and the notices shipped with Qt.
  • openpyxl reads and writes Excel workbooks.
  • Pillow handles images.
  • Tesseract and the English language model are installed separately for optional OCR.

This source checkout contains no dependency wheels, OCR models, or redistributed application executable.
