Xtractor Community Quick Start

On this page
  • 1. Select PDFs
  • 2. Open a representative PDF and mark fields
  • 3. Choose text or OCR
  • 4. Choose an output and start
  • 5. Review the result

1. Select PDFs

Use Browse Folder to scan a folder and its subfolders, or drop PDFs into the workspace. Check the files you want to include in the workbook.

2. Open a representative PDF and mark fields

Double-click a PDF in the file list. Drag a box around each field you need. Xtractor lists the areas in the sidebar and uses their numbered names as Excel headers. To adjust a box, use Resize. To remove one, use Delete.

3. Choose text or OCR

Leave Use OCR for scanned PDFs unchecked for searchable PDFs. Check it if the text is part of a scanned image.

4. Choose an output and start

Click Save to… and choose an Excel filename ending in .xlsx. Then click Extract to Excel. The progress dialog lets you cancel a running extraction.

5. Review the result

Open the workbook and compare a few rows with their original PDFs. Check the selected areas on several files if the layouts differ.

See the User Guide for more on the workspace and workbook, or open Troubleshooting for help with errors.
